# Kaiju Pet Desktop Companion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an optional, separately-launched `kaiju-pet` native desktop companion (macOS-first) that reflects fleet state, surfaces attention events, and sends one-line replies through the existing daemon HTTP API.

**Architecture:** A new `crates/kaiju-pet` workspace member builds a standalone `eframe`/`egui` binary. A background worker thread owns the HTTP client and a 2s poll loop; it feeds immutable snapshots to a **pure reducer** (aggregate state, attention ordering, transition detection, unread) over an `mpsc` channel; the egui UI renders the reducer's output and sends `UiCmd`s back. No daemon or core changes for the MVP. The pet is excluded from `default-members` so daemon/CLI builds never take the GUI dependency.

**Tech Stack:** Rust 2021, `eframe`/`egui` 0.28 (pinned), `reqwest` (blocking), `serde`/`serde_json`, `thiserror`. Sound via `afplay` (macOS). Tests via `cargo test` + a spawned `axum` stub daemon for HTTP integration.

## Global Constraints

- No `unwrap()`/`expect()`/`panic!()` outside tests and startup validation. Errors flow through `Result<T, PetError>`. (CLAUDE.md)
- The daemon, CLI, and dashboard MUST build and run without building the pet: `cargo build` (default-members) excludes `kaiju-pet`; only `cargo build -p kaiju-pet` builds it.
- No daemon endpoint changes, no core `Agent` changes for the MVP.
- Default daemon URL `http://127.0.0.1:7800`; poll `GET /agents` every 2s.
- Status wire strings are the **no-underscore** Debug-lowercased form: `starting`, `running`, `waitingforinput`, `stuck`, `limited`, `error`, `completed`, `stopped`. Unknown strings decode to a non-attention `Unknown` state, never panic.
- Terminal statuses = `completed`, `stopped`, `error` (mirror `AgentStatus::is_terminal`). Reply input is disabled for these and while disconnected.
- Max reply 4 KiB UTF-8; reject empty, newline, NUL, and other control characters before sending. Never auto-retry a reply.
- Reply text is never logged and is cleared from memory/UI after a successful send or on agent switch.
- Ship gate before merge: `cargo fmt --all`, `cargo clippy --workspace -p kaiju-pet -- -D warnings`, `cargo test --workspace -p kaiju-pet`. (see memory: kaiju-ship-gate)

```rust
use serde::Deserialize;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Status {
    Starting,
    Running,
    WaitingForInput,
    Stuck,
    Limited,
    Error,
    Completed,
    Stopped,
    Unknown,
}

/// Parse the daemon's Debug-lowercased status string (api.rs:228).
/// NOTE: the daemon emits `waitingforinput` (no underscore), not serde's
/// `waiting_for_input`. Any unrecognized value maps to `Unknown`.
pub fn parse_status(s: &str) -> Status {
    match s {
        "starting" => Status::Starting,
        "running" => Status::Running,
        "waitingforinput" => Status::WaitingForInput,
        "stuck" => Status::Stuck,
        "limited" => Status::Limited,
        "error" => Status::Error,
        "completed" => Status::Completed,
        "stopped" => Status::Stopped,
        _ => Status::Unknown,
    }
}

impl Status {
    pub fn is_terminal(&self) -> bool {
        matches!(self, Status::Completed | Status::Stopped | Status::Error)
    }

    pub fn is_attention(&self) -> bool {
        matches!(
            self,
            Status::WaitingForInput | Status::Stuck | Status::Limited | Status::Error
        )
    }

    pub fn is_active(&self) -> bool {
        matches!(
            self,
            Status::Starting
                | Status::Running
                | Status::WaitingForInput
                | Status::Stuck
                | Status::Limited
        )
    }
}

#[derive(Debug, Clone, Deserialize)]
struct RawAgent {
    id: String,
    agent_type: String,
    status: String,
    workspace: String,
    #[serde(default)]
    prompt: Option<String>,
    updated_at: String,
    session_name: String,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AgentSnapshot {
    pub id: String,
    pub agent_type: String,
    pub status: Status,
    pub workspace: String,
    pub prompt: Option<String>,
    pub updated_at: String,
    pub session_name: String,
}

pub fn decode_agents(body: &str) -> Result<Vec<AgentSnapshot>, serde_json::Error> {
    let raw: Vec<RawAgent> = serde_json::from_str(body)?;
    Ok(raw
        .into_iter()
        .map(|r| AgentSnapshot {
            id: r.id,
            agent_type: r.agent_type,
            status: parse_status(&r.status),
            workspace: r.workspace,
            prompt: r.prompt,
            updated_at: r.updated_at,
            session_name: r.session_name,
        })
        .collect())
}
```

```rust
use thiserror::Error;

#[derive(Debug, Error, PartialEq, Eq)]
pub enum PetError {
    #[error("cannot reach daemon")]
    Transport,
    #[error("authentication required")]
    AuthRequired,
    #[error("agent no longer exists")]
    AgentGone,
    #[error("agent is not running")]
    AgentTerminal,
    #[error("daemon error ({0})")]
    Server(u16),
    #[error("malformed daemon response")]
    Decode,
    #[error("unexpected response ({0})")]
    Unknown(u16),
}

impl PetError {
    pub fn from_status(code: u16) -> PetError {
        match code {
            401 => PetError::AuthRequired,
            404 => PetError::AgentGone,
            409 => PetError::AgentTerminal,
            500..=599 => PetError::Server(code),
            _ => PetError::Unknown(code),
        }
    }
}
```

```rust
const MAX_REPLY_BYTES: usize = 4096;

#[derive(Debug, PartialEq, Eq)]
pub enum ReplyError {
    Empty,
    TooLarge,
    ControlChar,
}

/// Trim, then reject empty, oversized, or control-bearing replies.
/// Any Unicode control char (category Cc), including \n \r \t \0, is rejected
/// because the daemon appends its own Enter via tmux send_keys.
pub fn validate_reply(raw: &str) -> Result<String, ReplyError> {
    let trimmed = raw.trim();
    if trimmed.is_empty() {
        return Err(ReplyError::Empty);
    }
    if trimmed.len() > MAX_REPLY_BYTES {
        return Err(ReplyError::TooLarge);
    }
    if trimmed.chars().any(|c| c.is_control()) {
        return Err(ReplyError::ControlChar);
    }
    Ok(trimmed.to_string())
}
```

```rust
/// Strip ANSI/control sequences from a captured tmux pane, then return the
/// last `n` non-empty lines as plain text. Never renders as rich text.
pub fn clean_log_tail(raw: &str, n: usize) -> Vec<String> {
    let stripped = strip_ansi_escapes::strip(raw.as_bytes());
    let text = String::from_utf8_lossy(&stripped);
    let lines: Vec<String> = text
        .lines()
        .map(|l| l.trim_end().to_string())
        .filter(|l| !l.trim().is_empty())
        .collect();
    let start = lines.len().saturating_sub(n);
    lines[start..].to_vec()
}
```

```rust
use std::collections::{HashMap, HashSet};

use crate::model::{AgentSnapshot, Status};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum VisualState {
    Disconnected,
    Idle,
    Working,
    Waiting,
    Stuck,
    Limited,
    Error,
    Celebrate,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AttentionEvent {
    pub agent_id: String,
    pub status: Status,
    pub updated_at: String,
}

#[derive(Debug, Clone)]
pub struct ReducerOutput {
    pub visual: VisualState,
    pub ordered_attention: Vec<AgentSnapshot>,
    pub new_events: Vec<AttentionEvent>,
    pub unread_count: usize,
}

pub struct Reducer {
    prev: HashMap<String, Status>,
    unread: HashSet<String>,
    // Set true after the next snapshot must be treated as a baseline
    // (startup or first snapshot after a disconnect) — no events, no sound.
    baseline_next: bool,
}

impl Reducer {
    pub fn new() -> Self {
        Reducer {
            prev: HashMap::new(),
            unread: HashSet::new(),
            baseline_next: true,
        }
    }

    pub fn on_disconnect(&mut self) -> ReducerOutput {
        self.baseline_next = true;
        ReducerOutput {
            visual: VisualState::Disconnected,
            ordered_attention: Vec::new(),
            new_events: Vec::new(),
            unread_count: self.unread.len(),
        }
    }

    pub fn mark_read(&mut self, agent_id: &str) {
        self.unread.remove(agent_id);
    }

    pub fn on_snapshot(&mut self, agents: &[AgentSnapshot]) -> ReducerOutput {
        let is_baseline = self.baseline_next;
        self.baseline_next = false;

        let mut new_events = Vec::new();
        let mut just_completed = false;

        for a in agents {
            let previous = self.prev.get(&a.id).copied();
            let changed = previous != Some(a.status);
            if changed && !is_baseline {
                if a.status.is_attention() {
                    new_events.push(AttentionEvent {
                        agent_id: a.id.clone(),
                        status: a.status,
                        updated_at: a.updated_at.clone(),
                    });
                    self.unread.insert(a.id.clone());
                }
                if a.status == Status::Completed {
                    just_completed = true;
                }
            }
            // On a baseline snapshot, existing attention agents still count as unread
            // so the badge is populated — but no event/sound is produced.
            if is_baseline && a.status.is_attention() {
                self.unread.insert(a.id.clone());
            }
        }

        // Rebuild prev from the current snapshot; drop agents that disappeared.
        self.prev = agents.iter().map(|a| (a.id.clone(), a.status)).collect();
        let present: HashSet<&str> = agents.iter().map(|a| a.id.as_str()).collect();
        self.unread.retain(|id| present.contains(id.as_str()));

        let ordered_attention = order_attention(agents);
        let visual =
            select_visual(agents, &ordered_attention, just_completed);

        ReducerOutput {
            visual,
            ordered_attention,
            new_events,
            unread_count: self.unread.len(),
        }
    }
}

fn priority(status: Status) -> u8 {
    match status {
        Status::WaitingForInput => 0,
        Status::Stuck => 1,
        Status::Limited => 2,
        Status::Error => 3,
        _ => 4,
    }
}

fn order_attention(agents: &[AgentSnapshot]) -> Vec<AgentSnapshot> {
    let mut attention: Vec<AgentSnapshot> =
        agents.iter().filter(|a| a.status.is_attention()).cloned().collect();
    // Priority ascending, then most recent updated_at first. RFC3339 strings
    // sort lexicographically in timestamp order for a fixed offset.
    attention.sort_by(|a, b| {
        priority(a.status)
            .cmp(&priority(b.status))
            .then_with(|| b.updated_at.cmp(&a.updated_at))
    });
    attention
}

fn select_visual(
    agents: &[AgentSnapshot],
    ordered_attention: &[AgentSnapshot],
    just_completed: bool,
) -> VisualState {
    if just_completed {
        return VisualState::Celebrate;
    }
    if let Some(top) = ordered_attention.first() {
        return match top.status {
            Status::WaitingForInput => VisualState::Waiting,
            Status::Stuck => VisualState::Stuck,
            Status::Limited => VisualState::Limited,
            Status::Error => VisualState::Error,
            _ => VisualState::Working,
        };
    }
    if agents.iter().any(|a| a.status.is_active()) {
        VisualState::Working
    } else {
        VisualState::Idle
    }
}
```

```rust
pub fn clamp_to_bounds(pos: WindowPos, bounds: (i32, i32, i32, i32)) -> WindowPos {
    let (min_x, min_y, max_x, max_y) = bounds;

        x: pos.x.clamp(min_x, max_x),

/// `~/Library/Application Support/kaiju/pet.json` on macOS via dirs-less lookup.
pub fn config_path() -> PathBuf {
    let base = std::env::var("XDG_CONFIG_HOME")
        .map(PathBuf::from)
        .unwrap_or_else(|_| {
            let home = std::env::var("HOME").unwrap_or_else(|_| ".".to_string());
            PathBuf::from(home).join(".config")
        });
    base.join("kaiju").join("pet.json")
}

pub fn load() -> Prefs {
    match std::fs::read_to_string(config_path()) {
        Ok(body) => serde_json::from_str(&body).unwrap_or_default(),
        Err(_) => Prefs::default(),
    }
}

pub fn save(p: &Prefs) -> Result<(), std::io::Error> {
    let path = config_path();
    if let Some(parent) = path.parent() {
        std::fs::create_dir_all(parent)?;
    }
    let body = serde_json::to_string_pretty(p)
        .map_err(|e| std::io::Error::new(std::io::ErrorKind::InvalidData, e))?;
    std::fs::write(path, body)
}
```

```rust
    pub fn new(base: String, token: Option<String>) -> Self {
        let http = reqwest::blocking::Client::builder()
            .timeout(std::time::Duration::from_secs(5))
            .build()
            .unwrap_or_else(|_| reqwest::blocking::Client::new());
        Client {

        }

        match &self.token {
            Some(t) => rb.bearer_auth(t),
            None => rb,
        }
    }

        let url = format!("{}/agents", self.base);
        let resp = self
            .auth(self.http.get(&url))
            .send()
            .map_err(|_| PetError::Transport)?;
        let code = resp.status().as_u16();
        if !resp.status().is_success() {
            return Err(PetError::from_status(code));
        }
        let body = resp.text().map_err(|_| PetError::Transport)?;
        decode_agents(&body).map_err(|_| PetError::Decode)
    }

    pub fn send_input(&self, id: &str, text: &str) -> Result<(), PetError> {
        let url = format!("{}/agents/{}/input", self.base, id);
        let resp = self
            .auth(self.http.post(&url).json(&serde_json::json!({ "text": text })))
            .send()
            .map_err(|_| PetError::Transport)?;
        if resp.status().is_success() {
            Ok(())
        } else {
            Err(PetError::from_status(resp.status().as_u16()))
        }
    }

    pub fn get_log_tail(&self, id: &str, n: usize) -> Result<Vec<String>, PetError> {
        let url = format!("{}/agents/{}/logs", self.base, id);
        let resp = self
            .auth(self.http.get(&url))
            .send()
            .map_err(|_| PetError::Transport)?;
        if !resp.status().is_success() {
            return Err(PetError::from_status(resp.status().as_u16()));
        }
        let body: serde_json::Value = resp.json().map_err(|_| PetError::Decode)?;
        let logs = body.get("logs").and_then(|v| v.as_str()).unwrap_or("");
        Ok(clean_log_tail(logs, n))
    }
```

### Task 9: Background poller worker with backoff

**Files:**
- Create: `crates/kaiju-pet/src/poller.rs`

**Interfaces:**
- Consumes: `client::Client`, `reducer::Reducer`, `model::AgentSnapshot`, `error::PetError`.
- Produces:
  - `enum WorkerMsg { Snapshot(reducer::ReducerOutput), Disconnected, LogTail{ id: String, lines: Result<Vec<String>, PetError> }, SendResult{ id: String, result: Result<(), PetError> } }`
  - `enum UiCmd { FetchLogs(String), SendReply { id: String, text: String }, RetryNow, Shutdown }`
  - `fn spawn_worker(client: Client, ctx: egui::Context) -> (std::sync::mpsc::Sender<UiCmd>, std::sync::mpsc::Receiver<WorkerMsg>)`

Backoff schedule after a failed poll: 2s, 5s, 10s, 30s (capped), reset to 2s on success. `RetryNow` collapses the wait immediately. This module owns the only `Reducer` instance so transition state lives on the worker thread.

- [ ] **Step 1: Write the poller (no unit test — timing/IO thread; covered by manual verification + the client integration tests)**

```rust
use std::sync::mpsc::{self, Receiver, Sender};
use std::time::{Duration, Instant};

use crate::client::Client;
use crate::error::PetError;
use crate::reducer::{Reducer, ReducerOutput};

pub enum WorkerMsg {
    Snapshot(ReducerOutput),
    Disconnected,
    LogTail { id: String, lines: Result<Vec<String>, PetError> },
    SendResult { id: String, result: Result<(), PetError> },
}

pub enum UiCmd {
    FetchLogs(String),
    SendReply { id: String, text: String },
    RetryNow,
    Shutdown,
}

const BACKOFF: [u64; 4] = [2, 5, 10, 30];

pub fn spawn_worker(
    client: Client,
    ctx: egui::Context,
) -> (Sender<UiCmd>, Receiver<WorkerMsg>) {
    let (cmd_tx, cmd_rx) = mpsc::channel::<UiCmd>();
    let (msg_tx, msg_rx) = mpsc::channel::<WorkerMsg>();

    std::thread::spawn(move || {
        let mut reducer = Reducer::new();
        let mut fail_streak: usize = 0;
        let mut next_poll = Instant::now();

        loop {
            // Drain UI commands (non-blocking) before deciding to poll.
            while let Ok(cmd) = cmd_rx.try_recv() {
                match cmd {
                    UiCmd::Shutdown => return,
                    UiCmd::RetryNow => next_poll = Instant::now(),
                    UiCmd::FetchLogs(id) => {
                        let lines = client.get_log_tail(&id, 5);
                        let _ = msg_tx.send(WorkerMsg::LogTail { id, lines });
                        ctx.request_repaint();
                    }
                    UiCmd::SendReply { id, text } => {
                        let result = client.send_input(&id, &text);
                        let _ = msg_tx.send(WorkerMsg::SendResult { id, result });
                        ctx.request_repaint();
                    }
                }
            }

            if Instant::now() >= next_poll {
                match client.get_agents() {
                    Ok(agents) => {
                        fail_streak = 0;
                        let out = reducer.on_snapshot(&agents);
                        let _ = msg_tx.send(WorkerMsg::Snapshot(out));
                        next_poll = Instant::now() + Duration::from_secs(2);
                    }
                    Err(_) => {
                        let out = reducer.on_disconnect();
                        let _ = msg_tx.send(WorkerMsg::Snapshot(out));
                        let idx = fail_streak.min(BACKOFF.len() - 1);
                        next_poll = Instant::now() + Duration::from_secs(BACKOFF[idx]);
                        fail_streak += 1;
                    }
                }
                ctx.request_repaint();
            }

            std::thread::sleep(Duration::from_millis(100));
        }
    });

    (cmd_tx, msg_rx)
}
```

The app owns UI-only state (`expanded: bool`, `selected: Option<String>`, `reply_text: String`, `send_in_flight: bool`, `last_output: ReducerOutput`, `log_lines: Vec<String>`, `status_line: String`). It drains `WorkerMsg` each frame, plays the cue on `new_events` (respecting `prefs.sound` and pause), and renders per `VisualState`. This is verified manually (Task 13), not unit-tested.

- [ ] **Step 1: Write the app**

```rust
use eframe::egui;

use crate::poller::{UiCmd, WorkerMsg};
use crate::reducer::{ReducerOutput, VisualState};

pub struct PetApp {
    cmd_tx: std::sync::mpsc::Sender<UiCmd>,
    msg_rx: std::sync::mpsc::Receiver<WorkerMsg>,
    prefs: crate::prefs::Prefs,
    out: ReducerOutput,
    expanded: bool,
    selected: Option<String>,
    reply_text: String,
    send_in_flight: bool,
    status_line: String,
    log_lines: Vec<String>,
}

impl PetApp {
    pub fn new(
        cmd_tx: std::sync::mpsc::Sender<UiCmd>,
        msg_rx: std::sync::mpsc::Receiver<WorkerMsg>,
        prefs: crate::prefs::Prefs,
    ) -> Self {
        PetApp {
            cmd_tx,
            msg_rx,
            prefs,
            out: ReducerOutput {
                visual: VisualState::Idle,
                ordered_attention: Vec::new(),
                new_events: Vec::new(),
                unread_count: 0,
            },
            expanded: false,
            selected: None,
            reply_text: String::new(),
            send_in_flight: false,
            status_line: String::new(),
            log_lines: Vec::new(),
        }
    }

    fn drain_messages(&mut self) {
        while let Ok(msg) = self.msg_rx.try_recv() {
            match msg {
                WorkerMsg::Snapshot(out) => {
                    if !out.new_events.is_empty() && self.prefs.sound {
                        crate::window::play_cue();
                    }
                    // Keep a valid selection; default to the top attention agent.
                    if self.selected.is_none() {
                        self.selected = out.ordered_attention.first().map(|a| a.id.clone());
                    }
                    self.out = out;
                }
                WorkerMsg::Disconnected => {}
                WorkerMsg::LogTail { id: _, lines } => {
                    self.log_lines = lines.unwrap_or_else(|_| vec!["Context unavailable".into()]);
                }
                WorkerMsg::SendResult { id: _, result } => {
                    self.send_in_flight = false;
                    match result {
                        Ok(()) => {
                            self.reply_text.clear();
                            self.status_line = "Sent".into();
                        }
                        Err(e) => self.status_line = format!("{e}"),
                    }
                }
            }
        }
    }

    fn label_for(v: VisualState) -> &'static str {
        match v {
            VisualState::Disconnected => "Disconnected",
            VisualState::Idle => "All quiet",
            VisualState::Working => "Working",
            VisualState::Waiting => "Needs you",
            VisualState::Stuck => "Stuck",
            VisualState::Limited => "Rate-limited",
            VisualState::Error => "Error",
            VisualState::Celebrate => "Done!",
        }
    }

    fn draw_bubble(&mut self, ui: &mut egui::Ui) {
        let attention = self.out.ordered_attention.clone();
        ui.label(format!(
            "{} · {} need you",
            Self::label_for(self.out.visual),
            self.out.unread_count
        ));

        if attention.len() > 1 {
            egui::ComboBox::from_label("Agent")
                .selected_text(self.selected.clone().unwrap_or_default())
                .show_ui(ui, |ui| {
                    for a in &attention {
                        ui.selectable_value(&mut self.selected, Some(a.id.clone()), &a.id);
                    }
                });
        }

        let Some(sel_id) = self.selected.clone() else { return };
        let Some(agent) = attention.iter().find(|a| a.id == sel_id).cloned() else {
            self.status_line = "Agent no longer present".into();
            return;
        };

        // Mark read (badge only) and load logs once when this agent is shown.
        self.cmd_tx.send(UiCmd::FetchLogs(sel_id.clone())).ok();

        ui.separator();
        ui.label(format!("{} · {} · {:?}", &agent.id, &agent.agent_type, agent.status));
        if let Some(p) = &agent.prompt {
            ui.label(egui::RichText::new(truncate_two_lines(p)).weak());
        }
        for line in &self.log_lines {
            ui.small(line);
        }

        ui.separator();
        let terminal = agent.status.is_terminal() || self.out.visual == VisualState::Disconnected;
        if terminal {
            if ui.button("Open dashboard").clicked() {
                let _ = open_dashboard(&self.prefs.daemon_url);
            }
            return;
        }

        ui.horizontal(|ui| {
            let field = ui.add_enabled(
                !self.send_in_flight,
                egui::TextEdit::singleline(&mut self.reply_text).desired_width(150.0),
            );
            let enter = field.lost_focus() && ui.input(|i| i.key_pressed(egui::Key::Enter));
            let send = ui.add_enabled(!self.send_in_flight, egui::Button::new("Send")).clicked();
            if enter || send {
                match crate::validate::validate_reply(&self.reply_text) {
                    Ok(text) => {
                        self.send_in_flight = true;
                        self.status_line.clear();
                        self.cmd_tx.send(UiCmd::SendReply { id: sel_id.clone(), text }).ok();
                    }
                    Err(_) => self.status_line = "Enter one line of text".into(),
                }
            }
        });
        if !self.status_line.is_empty() {
            ui.small(&self.status_line);
        }
    }
}

impl eframe::App for PetApp {
    fn clear_color(&self, _v: &egui::Visuals) -> [f32; 4] {
        [0.0, 0.0, 0.0, 0.0] // transparent
    }

    fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
        self.drain_messages();
        egui::CentralPanel::default().show(ctx, |ui| {
            let badge = if self.out.unread_count > 0 {
                format!("  ({})", self.out.unread_count)
            } else {
                String::new()
            };
            let pet = ui.button(format!("🦉 {}{}", Self::label_for(self.out.visual), badge));
            if pet.clicked() {
                self.expanded = !self.expanded;
            }
            if self.expanded {
                self.draw_bubble(ui);
                if ui.input(|i| i.key_pressed(egui::Key::Escape)) {
                    self.expanded = false;
                }
            }
        });
    }
}

fn truncate_two_lines(s: &str) -> String {
    let max = 140;
    if s.len() <= max { s.to_string() } else { format!("{}…", &s[..max]) }
}

fn open_dashboard(url: &str) -> std::io::Result<()> {
    #[cfg(target_os = "macos")]
    { std::process::Command::new("open").arg(url).spawn().map(|_| ()) }
    #[cfg(not(target_os = "macos"))]
    { let _ = url; Ok(()) }
}
```
